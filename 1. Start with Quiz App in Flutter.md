# QuizApp (Flutter)

Objective: Learn To Create A Quiz App in Flutter

Prerequisites
None — this is the first project. It pairs with [2. Get Quiz Data From Network in Flutter.md](2.%20Get%20Quiz%20Data%20From%20Network%20in%20Flutter.md) as the next step.

This app shows **one question at a time** and rebuilds that single widget as the user answers, using a `StatefulWidget` and `setState`.

#### Step 1: Scaffold the project ####
  ```bash
  flutter create quiz_app
  cd quiz_app
  ```
- Add the fonts package used for styling:
  ```bash
  flutter pub add google_fonts
  ```

#### Step 2: Define the `QuizQuestion` model ####
- `lib/models/quiz_questions.dart`:
  ```dart
  class QuizQuestion {
    const QuizQuestion(this.text, this.answers);

    final String text;
    final List<String> answers;

    List<String> get shuffledAnswers {
      final shuffledList = List.of(answers);
      shuffledList.shuffle();
      return shuffledList;
    }
  }
  ```
- By convention, `answers[0]` is always the correct answer.

#### Step 3: Add the static question bank ####
- `lib/models/sample_question.dart`:
  ```dart
  const questions = [
    QuizQuestion('What are the main building blocks of Flutter UIs?', [
      'Widgets',
      'Components',
      'Blocks',
      'Functions',
    ]),
    // ...more questions, correct answer always listed first
  ];
  ```
- This static list is what the whole app runs on until [doc 2](2.%20Get%20Quiz%20Data%20From%20Network%20in%20Flutter.md) replaces it with a live fetch from Open Trivia DB.

#### Step 4: Build the answer button ####
- `lib/screen/elevated_button.dart`:
  ```dart
  class AnswerButton extends StatelessWidget {
    const AnswerButton({super.key, required this.text, required this.onTap});

    final String text;
    final void Function()? onTap;

    @override
    Widget build(BuildContext context) {
      return Column(
        crossAxisAlignment: CrossAxisAlignment.stretch,
        children: [
          const SizedBox(height: 10),
          ElevatedButton(
            onPressed: onTap,
            style: ElevatedButton.styleFrom(
              padding: const EdgeInsets.symmetric(vertical: 10, horizontal: 10),
              backgroundColor: const Color.fromARGB(255, 33, 37, 45),
              foregroundColor: Colors.white,
              shape: RoundedRectangleBorder(
                borderRadius: BorderRadius.circular(40),
              ),
            ),
            child: Text(
              text,
              textAlign: TextAlign.center,
              style: GoogleFonts.smoochSans(
                color: Colors.white,
                fontSize: 20,
                fontWeight: FontWeight.bold,
              ),
            ),
          ),
        ],
      );
    }
  }
  ```

#### Step 5: Build the question screen ####
- One `StatefulWidget` tracks `currentQuestionIndex` and rebuilds itself for each question.
- `lib/screen/question_screen.dart` (core shape — network fetching replaces the plain `questions` list in doc 2):
  ```dart
  class _QuestionScreenState extends State<QuestionScreen> {
    var currentQuestionIndex = 0;
    final selectedAnswers = <String>[];

    void answerQuestion(String answer) {
      selectedAnswers.add(answer);
      if (selectedAnswers.length == questions.length) {
        // last question answered — move on to results (Step 7)
        return;
      }
      setState(() => currentQuestionIndex += 1);
    }

    @override
    Widget build(BuildContext context) {
      final currentQuestion = questions[currentQuestionIndex];
      return Column(
        children: [
          Text(currentQuestion.text),
          ...currentQuestion.shuffledAnswers.map(
            (answer) => AnswerButton(
              text: answer,
              onTap: () => answerQuestion(answer),
            ),
          ),
        ],
      );
    }
  }
  ```
- Tapping an answer calls `setState()`, and Flutter re-runs `build()` for just this widget.

#### Step 6: Build the start screen with a name form ####
- Uses a `Form` for input validation (see [04.understand_flutter.md, Section 10](../Documents/AI/Workshop%20Planning/Material/04.understand_flutter.md#10-handling-user-input--forms)).
- `lib/screen/start_quiz_content.dart` — a `Form` with a `GlobalKey<FormState>`, a `TextEditingController` (disposed in `dispose()`), and a validator requiring a non-empty name before the quiz can start.

#### Step 7: Wire up navigation between screens ####
- `Navigator` moves between three separate screens: start, question, and results.
- `lib/screen/start_quiz_screen.dart`:
  ```dart
  class StartQuizScreen extends StatelessWidget {
    const StartQuizScreen({super.key});

    void _startQuiz(BuildContext context, String playerName) {
      Navigator.push(
        context,
        MaterialPageRoute(
          builder: (context) => QuestionScreen(playerName: playerName),
        ),
      );
    }

    @override
    Widget build(BuildContext context) {
      return Scaffold(
        body: GradientBackground(
          child: StartQuizContent((playerName) => _startQuiz(context, playerName)),
        ),
      );
    }
  }
  ```
- Once the last question is answered, `QuestionScreen` does `Navigator.pushReplacement(...)` to the results screen, passing `playerName` and the collected answers forward through the constructor. The results screen's Restart button calls `Navigator.popUntil(context, (route) => route.isFirst)` to return to the start screen.

#### Step 8: Build the results screen ####
- `lib/models/quiz_summary_item.dart`:
  ```dart
  class QuizSummaryItem {
    const QuizSummaryItem({
      required this.questionIndex,
      required this.question,
      required this.correctAnswer,
      required this.userAnswer,
    });

    final int questionIndex;
    final String question;
    final String correctAnswer;
    final String userAnswer;

    bool get isCorrectAnswer => userAnswer == correctAnswer;
  }
  ```
- `lib/screen/quiz_summary/result_screen.dart` builds a `List<QuizSummaryItem>` from the questions and the user's answers — using `questions[i].answers[0]` as the correct answer, per Step 2's convention — counts how many are correct, and displays them via `QuestionsSummary` → `SummaryItem` → `QuestionIdentifier` (a small colored badge per question, green/pink depending on `isCorrectAnswer`).

#### Step 9: Shared styling ####
- `lib/screen/gradient_background.dart` — one small widget wrapping every screen's body in the same blue gradient, so the styling isn't duplicated across the three screens:
  ```dart
  class GradientBackground extends StatelessWidget {
    const GradientBackground({super.key, required this.child});
    final Widget child;

    @override
    Widget build(BuildContext context) {
      return Container(
        decoration: const BoxDecoration(
          gradient: LinearGradient(colors: [Colors.blue, Colors.blueAccent]),
        ),
        child: Center(child: child),
      );
    }
  }
  ```
- `MyApp` (`lib/main.dart`) sets up the single `MaterialApp` for the whole app, with `StartQuizScreen` as `home`.

#### Step 10: Verify ####
- `flutter analyze` — no issues.
- `flutter test` — a widget test confirms the start screen renders and the name field's validator blocks an empty submission.
- Run on a device/simulator and walk the golden path: enter a name → answer each question → see the results screen with a correct/incorrect breakdown → Restart returns to the start screen.
